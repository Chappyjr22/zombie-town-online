# Low Poly FPS Map Vol.1

81 glTF binary (`.glb`) models — houses, a gas station, bank, city hall,
church, office, road pieces, cars, fences, trees, and street clutter — used
as building blocks for a hand-placed town map, plus a shared 1024x1024
texture atlas (`Textures/Texture_01.png`, embedded in each `.glb` already;
the loose copy is kept for reference only and isn't loaded at runtime).

Source: https://www.cgtrader.com/3d-models/exterior/street-exterior/low-poly-fps-map-vol1

Provided to this repo already converted to glTF from the original Unreal
Engine project. License terms as stated by whoever supplied the file to this
project (free asset site, free to use) — not independently verified here,
since cgtrader.com is not reachable from this environment to confirm the
listing's exact license text.
