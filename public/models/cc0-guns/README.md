# CC0 Guns & Explosives

These five optimized GLB files were converted from the Free CC0 Guns & Explosives Pack:

- `makarov.glb` from Makarov
- `suomi-kp.glb` from Suomi KP
- `m4a1.glb` from M4A1
- `shotgun.glb` from Shotgun
- `sniper.glb` from Sniper

Source: https://3dmodelscc0.itch.io/free-cc0-guns-explosives-pack

The source FBX geometry and supplied PBR textures were converted to embedded glTF 2.0. Textures were resized for browser performance. Gameplay weapon IDs and stats remain unchanged.
