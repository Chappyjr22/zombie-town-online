# Quaternius Ultimate Gun Pack

Author: Quaternius  
Official source: https://quaternius.com/packs/ultimategun.html  
Archive mirror maintained by the author: https://quaternius.itch.io/50-lowpoly-guns  
License: CC0. See LICENSE.txt in this directory.

This directory contains an initial performance-safe pilot of the original OBJ and MTL files:

- Pistol_1 -> M1911
- AssaultRifle2_1 -> M4A1
- SubmachineGun_1 -> MP5
- Shotgun_2 -> Remington 870
- SniperRifle_1 -> DSR-50

The game keeps its procedural weapon meshes as instant-loading fallbacks. Ray Gun, Ray Gun Mark II, Thundergun, Wunderwaffe, Ballistic Knife, and War Machine remain custom game models.
