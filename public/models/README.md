## Soldier.glb

The mesh names (vanguard_Mesh and vanguard_visor), Mixamo bone names, and Idle, Walk, and Run clip set identify this as the standard Soldier.glb example distributed by the Three.js project.

Source reference: https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Soldier.glb  
Three.js repository license: MIT, https://github.com/mrdoob/three.js/blob/dev/LICENSE

The upstream example does not currently include a separate asset-specific license file. This note records the exact upstream reference instead of leaving the binary unattributed.
