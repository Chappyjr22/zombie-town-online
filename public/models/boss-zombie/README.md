# Boss zombie

`boss-zombie.glb` is derived from **Male City Zombie, Ready for use in Game
Engines** by Rikindle3D:

https://opengameart.org/content/male-city-zombie-ready-for-use-in-game-engines

The source asset is released under CC0 1.0. Attribution is not required, but the
source is recorded here for provenance.

The game-ready GLB was converted from the supplied FBX files and combines:

- the rigged character model and PBR textures
- walk, attack, hit, and death animations
- in-place animation tracks suitable for browser gameplay

The conversion intentionally keeps the model at 17,839 uploaded vertices and
one skinned source mesh with three material primitives, so only one boss has a
modest runtime cost.
