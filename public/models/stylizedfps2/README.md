# Stylized FPS Map 2

67 glTF binary (`.glb`) models — gas station/roadside diner buildings, floor and
roof pieces, fencing, barrels, a truck and cars, cafe furniture, trash, and
nature clutter (rocks, mushrooms, plants) — used as building blocks for a
hand-placed map, converted from the source FBX files using
[FBX2glTF](https://github.com/facebookincubator/FBX2glTF). Each model embeds a
single BaseColor texture downscaled to 512x512 (no normal/mask maps), matching
the flat-shaded lowpoly look used by the other maps in this repo.

Source pack: "Stylized FPS Map 2" — provided as a raw FBX export
(`StylizedFPS2_FBX_1.0.zip`) plus a companion Unity project
(`JC_StylizedFPS2_2022.3.1_SRP_v1.0.unitypackage`) containing a demo scene
with the pack's authored layout. License terms as stated by whoever supplied
the files to this project — not independently verified here.
